# MiniSocial : Mini Réseau Social en Solidity

Atelier 3 : smart contract permettant de publier et consulter des messages sur la blockchain.

## Fonctionnalités
- `publishPost(string _message)` : publie un message (auteur = msg.sender)
- `getPost(uint index)` : retourne le message et l'auteur d'un post
- `getTotalPosts()` : retourne le nombre total de posts
